# Slides / Slide trình bày

Place the final presentation at:

```text
slides/slides.pdf
```

### Graphical path

Open the group repository on GitHub, choose **Add file → Upload files**, upload
`slides.pdf`, inspect the changed filename, and commit to an appropriate branch.
A pull request may be used for group review before merging.

### Terminal path

```bash
git add slides/slides.pdf
git commit -m "Add final presentation slides"
git push
```

Editable slide source files may also be stored here when available.

## Project title

Search Strategies for a Synthetic Campus-Routing Graph

## Topic source

Adapted from the course search materials; the group defined its own problem and scope.

## Exact selected problem

Determine how breadth-first search, uniform-cost search, and A* differ in path
cost and search effort on the same reproducibly generated weighted campus-routing
graphs, including cases where the fewest-edge route is not the least-cost route.

## Class-visible summary

We will compare the three algorithms on generated campus-style graphs with
nonnegative edge costs. We will measure solution cost, expanded nodes, and
running time, then explain when each method is appropriate.

## Student-defined scope and feasibility

We will implement three algorithms, one deterministic graph generator, and a
small experiment suite. We will not use real location traces, deploy a navigation
service, or claim conclusions beyond the tested graph families. The work uses
synthetic data and standard Python.

## Planned method, data, tools, and sources

Adjacency-list graphs, positive integer costs, seeded synthetic instances,
breadth-first search, uniform-cost search, A* with an admissible coordinate
heuristic, Python 3, and course Week 6 search materials.

## Expected output or demonstration

A command-line demonstration, reproducible CSV measurements, comparison plots or
tables, and a discussion of path cost versus search effort.

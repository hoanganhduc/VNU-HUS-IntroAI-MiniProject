## Project title / Tên dự án

<!-- BEGIN:PROJECT_TITLE -->
Search Strategies for a Synthetic Campus-Routing Graph
<!-- END:PROJECT_TITLE -->

## Topic source / Nguồn chủ đề

<!-- BEGIN:TOPIC_SOURCE -->
The group adapted the search-algorithm direction in the course materials and
defined its own synthetic routing problem, experimental questions, and scope.
<!-- END:TOPIC_SOURCE -->

## Short class-visible summary / Tóm tắt công khai trong lớp

<!-- BEGIN:PUBLIC_SUMMARY -->
We will compare breadth-first search, uniform-cost search, and A* on generated
campus-style graphs with nonnegative edge costs. We will measure solution cost,
expanded nodes, and running time, then explain when each method is appropriate.
<!-- END:PUBLIC_SUMMARY -->

## Exact selected problem / Bài toán cụ thể đã chọn

<!-- BEGIN:SELECTED_PROBLEM -->
Determine how breadth-first search, uniform-cost search, and A* differ in path
cost and search effort on the same reproducibly generated weighted campus-routing
graphs, including cases where the fewest-edge route is not the least-cost route.
<!-- END:SELECTED_PROBLEM -->

## Problem and motivation / Bài toán và động lực

<!-- BEGIN:PROBLEM_AND_MOTIVATION -->
Students often see search algorithms on separate toy examples. A controlled
comparison on identical graphs can make completeness, optimality, path cost, and
heuristic guidance concrete. The project asks a bounded empirical question rather
than attempting to build a real navigation service.
<!-- END:PROBLEM_AND_MOTIVATION -->

## Student-defined scope and feasibility / Phạm vi và tính khả thi do nhóm xác định

<!-- BEGIN:SCOPE_AND_FEASIBILITY -->
The group will implement the three algorithms, one deterministic graph generator,
and a small experiment suite. It will not collect real location traces, deploy a
mobile application, solve dynamic traffic routing, or claim general conclusions
outside the tested graph families. The scope is feasible because it uses
synthetic data and standard Python on modest graph sizes.
<!-- END:SCOPE_AND_FEASIBILITY -->

## Planned approach or method / Phương pháp dự kiến

<!-- BEGIN:PLANNED_METHOD -->
Represent each graph by an adjacency list with positive integer costs. Run all
three algorithms on the same seeded instances. Use hop count for breadth-first
search, cumulative cost for uniform-cost search, and cumulative cost plus an
admissible coordinate-based heuristic for A*. Record correctness checks, returned
cost, expanded-node count, and elapsed time. Include a zero-heuristic check in
which A* should behave like uniform-cost search.
<!-- END:PLANNED_METHOD -->

## Data, tools, papers, and existing projects / Dữ liệu, công cụ và tài liệu

<!-- BEGIN:DATA_TOOLS_AND_SOURCES -->
The example uses only synthetic graphs generated by the project, Python 3, the
standard-library `heapq`, `csv`, and `time` modules, and the course Week 6 search
materials. A real group would record the exact Python version and any additional
sources it actually consults in `docs/EXTERNAL_RESOURCES.md`.
<!-- END:DATA_TOOLS_AND_SOURCES -->

## Expected output or demonstration / Kết quả hoặc phần minh họa dự kiến

<!-- BEGIN:EXPECTED_OUTPUT -->
A command-line demonstration, reproducible CSV measurements, plots or tables for
several seeded graph families, and a discussion of route cost versus search
effort. No numerical outcome is asserted in advance.
<!-- END:EXPECTED_OUTPUT -->

## Milestones / Các mốc thực hiện

<!-- BEGIN:MILESTONES -->
1. Finalize graph format and deterministic generator.
2. Implement and unit-check breadth-first and uniform-cost search.
3. Implement A* and verify heuristic admissibility on generated instances.
4. Run the common experiment matrix and inspect anomalous cases.
5. Complete the report, reproduction guide, slides, and declarations before the
   common final deadline.
<!-- END:MILESTONES -->

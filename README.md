## English

### Essential rules

- One founder accepts one Classroom50 **group** assignment.
- A group contains one to five students from the same course.
- The same private repository is used from topic proposal through the final
  examination.
- The proposal is required but receives no numerical score.
- The final project has no autograder, automatic score, Feedback PR, or
  `gh student submit` step.
- The exact proposal and final Git commit URLs posted in the group's topic issue
  identify the submitted versions.
- The final score is graded manually: **Report 60 points + Presentation 40
  points**.

### Graphical quick start

1. Open the final-project assignment link at <https://classroom50.org> and
   choose **Sign in with GitHub**.
2. Open the VNU-HUS organization marked **Student**.
3. Only the founder chooses **Accept**.
4. Use the edit pencil and **Manage collaborators** to add the other members.
5. Follow Classroom50's link to the GitHub repository.
6. On GitHub, choose **Code → Codespaces** or use another Git client.
7. Use the class topic-board repository's **Issues → New issue → Project topic
   proposal** form for the proposal summary.

The equivalent CLI commands and recovery steps are in the
[Submission Guide](Submission%20Guide.md). Screenshots are added only after the
pilot interface is verified; see the
[screenshot checklist](docs/images/classroom50/README.md).

## Tiếng Việt

### Quy tắc chính

- Một thành viên đại diện nhận một bài tập **nhóm** trên Classroom50.
- Mỗi nhóm có từ một đến năm sinh viên thuộc cùng một học phần.
- Nhóm sử dụng cùng một kho riêng tư từ lúc đề xuất chủ đề đến kỳ thi cuối kỳ.
- Đề xuất chủ đề là bắt buộc nhưng không có điểm số riêng.
- Dự án cuối kỳ không có chấm tự động, điểm tự động, Feedback PR, hoặc bước
  `gh student submit`.
- Phiên bản nộp được xác định bởi liên kết commit Git chính xác được đăng trong
  issue chủ đề của nhóm.
- Điểm cuối kỳ được chấm thủ công: **Báo cáo 60 điểm + Trình bày 40 điểm**.

### Bắt đầu bằng giao diện đồ họa

1. Mở liên kết bài tập dự án tại <https://classroom50.org> và chọn
   **Sign in with GitHub**.
2. Mở tổ chức VNU-HUS có nhãn **Student**.
3. Chỉ thành viên đại diện chọn **Accept**.
4. Dùng biểu tượng bút chì và **Manage collaborators** để thêm các thành viên
   còn lại.
5. Theo liên kết của Classroom50 tới kho GitHub của nhóm.
6. Trên GitHub, chọn **Code → Codespaces** hoặc dùng công cụ Git khác.
7. Trong kho chủ đề của lớp, chọn **Issues → New issue → Project topic
   proposal** để đăng bản tóm tắt đề xuất.

Các lệnh CLI tương đương và cách xử lý lỗi có trong
[Hướng dẫn nộp bài](Submission%20Guide.md). Ảnh chụp chỉ được thêm sau khi giao
diện thử nghiệm đã được kiểm tra; xem
[danh sách kiểm tra ảnh](docs/images/classroom50/README.md).

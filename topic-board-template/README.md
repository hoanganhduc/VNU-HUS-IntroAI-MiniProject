# Class project-topic board

This private repository is visible to the corresponding course and is not a
second Classroom50 assignment. Each final-project group uses exactly one GitHub
issue to publish its class-visible proposal summary, receive review, record
approved updates, and post the final commit URL.

## Student graphical workflow

1. Open this repository on GitHub.
2. Choose **Issues → New issue → Project topic proposal**.
3. Complete every required field.
4. Paste the exact proposal commit URL from the group's private Classroom50
   repository.
5. Submit the issue and keep using that same issue for the whole project.

### CLI fallback

The configured GitHub Issue Form is preferred. When a tested Markdown fallback
template is supplied, `gh issue create` may be used with that exact body. Do not
omit required fields.

## Privacy

Do not post student IDs, email addresses, phone numbers, credentials, private
keys, or other unnecessary personal information. Use GitHub usernames.

The issue is a class-visible summary. The linked private commit is the
authoritative full proposal. Some classmates may be unable to open another
group's private commit, but they can read the summary in this issue.

## One issue per group

- Proposal revisions are comments on the existing issue.
- Approved proposal updates are comments on the existing issue.
- The presentation schedule is added to the existing issue.
- The `FINAL SUBMISSION` commit URL is posted to the existing issue.
- Do not create a second issue for the same group unless staff explicitly
  instructs you to do so.

## Status labels

Staff use the labels listed in [`labels.md`](labels.md). Silence is not approval;
an approval comment must name the exact approved commit SHA.

## Topic overlap

A broad area such as chatbots, recommendation, or image classification is not
reserved by one group. Similar broad topics may coexist when their scope, data,
method, research question, or intended application differs meaningfully. The
instructor resolves close overlap during proposal review.

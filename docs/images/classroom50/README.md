# Classroom50 screenshot capture checklist

The textual browser paths in the project guides are complete. Screenshots are
added only after the corresponding workflow is verified in
`classroom50-pilot-2026` with dummy accounts.

Planned images:

```text
sign-in-and-organization.png
accept-final-project.png
manage-collaborators.png
open-project-repository.png
```

Every committed image must:

- use dummy accounts and repositories;
- contain no real names, student IDs, email addresses, tokens, private URLs, or
  grades;
- have descriptive alt text and a verification date in the referring guide;
- show readable labels and navigation landmarks;
- be accompanied by a complete text-only path.

Do not create a mock screenshot or imply that the final project has a Classroom50
**Submit** or meaningful **View grade** control. It does not.
